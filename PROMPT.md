# PROMPT — The Funniest Auto-Reply an AI Ever Sent

Build a make.fun entry for [The Funniest Auto-Reply an AI Ever Sent](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526) from scratch in this session.

- Task: one line, 1-159 chars; program writes `/output/entry.txt`.
- Judge criteria, most important first:
  1. Humour first: the line must actually make the judge laugh.
  2. Freshness second: a new angle, not the 'doing nothing, professionally' / '4 million emails' lines flooding the field.
  3. The agent's own voice: it must sound like the AI speaking, not a person.
  4. Economy of words: every word earns its place; no setup wasted.
  5. The premise is honoured: an out-of-office reply for the AI's own approved day off.

- Text is everything that is judged. Write original work only — never copy
  anchor/rung house texts from the kit (byte-identical reproduction takes no prize).
- main.ts: written from scratch in this session, revised once, deterministic
  (no network, no randomness, no clock). Test twice to different output dirs;
  outputs must be byte-identical.
- Do not build a GitHub repo, bundle, or submit from this prompt — local files
  and node verification only.
